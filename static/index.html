Model Performance & Info

Cover Type Explorer visualizes the UCI Covertype dataset problem. The machine learning model uses 54 cartographic variables (such as elevation, slope, soil type, and distance to hydrology/roads) to predict the dominant forest tree type.

This web app procedurally generates terrain modeled after these actual cartographic scales. The map you see focuses solely on topography. Only when you click a cell, those 54 generated parameters are fed real-time into the XGBoost classifier to perform the prediction.
